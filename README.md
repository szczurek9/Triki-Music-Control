# Triki Music Control
Skrypt bazuje na [Wojtekb30/unofficial-triki-api-py](https://github.com/Wojtekb30/unofficial-triki-api-py)

- obrót w prawo → następny
- obrót w lewo → poprzedni
- potrząśnięcie → play/pause

Skrypt czasem lekko świruje, bo go wygenerowalem z ai, jak chcesz to popraw pod swoje potrzeby. Mi odpowiada.

Aby skrypt zadziałał musisz mieć zainstalowanego pythona i w folder w którym będziesz go miał wrzucić plik TrikiPy.py, możesz go pobrać z repo podanego na samej górze readme.

Uruchom:
`py -m pip install -r requirements.txt`
`py music_controller.py`
